# Standalone completion checklist

The source requirements are the user-provided Material and Manpower Tracking document. Bidlark live integration and subscription payment processing are deferred by the user's standalone open-source direction. GPS and automatic payroll linkage are explicitly excluded by the specification; offline sync is identified as a later phase. Every item below requires a UI, server authorization/validation and regression evidence before it is complete.

- [x] Project grants, published GC snapshots, restricted labor financial subsystem, and organization setup/export/retention controls.
- [x] Catalog trade/classification/accessories, explicit unit conversions, source-reviewed imports, quote tiers/approval and shortage RFQs.
- [x] Issued PO revisions with approval, line backorders, split shipments, external PO provenance, returns/credits/replacements.
- [x] Serialized custody/warranty, condition/damage/adjustment review, reconciled stock and material timeline.
- [x] Per-worker calendars and shifts, breaks, region/supervisor, crew templates, allocation/priority and date-range staffing.
- [x] Field timer/manual check-in, worker review, job codes, evidence, and correction/reversal of production.
- [x] Dependency/material-aware calendar scenarios, overtime costing, reversible leveling suggestions and schedule revisions.
- [x] In-app dispatch and acknowledgements; durable event outbox with idempotency, retries and dead-letter monitoring.
- [x] Project/section/date-filtered material, financial, reliability, workforce, productivity, warranty and closeout reports; validated permission-gated payroll export.
- [ ] Regression acceptance, browser/mobile flows, recovery verification, migration and deployment documentation; updated release and CAS-TX promotion.
